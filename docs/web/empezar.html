01

Instalación

Cero no está publicado en Maven Central todavía, así que hay un instalador. Baja el paquete, comprueba su huella, lo compila, deja los artefactos en tu repositorio local de Maven y te pone la orden cero a mano. No pide contraseña y no escribe fuera de tu carpeta personal.

macOS y Linuxsh
curl -fsSL https://cero.ginit.dev/instalar | sh
WindowsPowerShell
irm https://cero.ginit.dev/instalar.ps1 | iex

Los dos guiones se sirven como texto plano a propósito: ábrelos en el navegador y léelos antes de ejecutarlos — instalar · instalar.ps1. Con --con-pruebas corre además las 1 761 pruebas durante la instalación.

Y si prefieres hacerlo a mano, es lo mismo paso a paso:

~/proyectos

Requisitos: git, Maven y un JDK 25 o superior. Nada más — Cero no tiene dependencias externas.

Después, en tu pom.xml, toma solo lo que uses:

pom.xmlXML
<dependency>
    <groupId>cero</groupId>
    <artifactId>cero-core</artifactId>   <!-- arrastra cero-http -->
    <version>0.3.0</version>
</dependency>

<!-- opcionales -->
<dependency><groupId>cero</groupId><artifactId>cero-view</artifactId><version>0.3.0</version></dependency>
<dependency><groupId>cero</groupId><artifactId>cero-data</artifactId><version>0.3.0</version></dependency>

<!-- el driver JDBC lo pone tu aplicación -->
<dependency><groupId>org.postgresql</groupId><artifactId>postgresql</artifactId><version>42.7.3</version></dependency>

02

En cinco minutos

Un controlador es una clase corriente. Lo que devuelve decide el formato: un objeto se serializa a JSON, un String sale como texto plano, null es un 204. Sin anotación de por medio.

Hola.javaJava
import cero.core.*;

@Route("/api/tareas")
public class TareaController {

    @Inject Tareas tareas;

    @Get
    public Object listar(@Query(value = "pagina", orElse = "1") int pagina) {
        return tareas.findPage(pagina, 20);
    }

    @Get("/{id}")
    public Object ver(@Path("id") long id) {
        return tareas.findById(id);
    }

    @Post
    public Object crear(@Body @Valid Tarea tarea) {
        return Result.created(tareas.insert(tarea));
    }
}

public static void main(String[] args) {
    Cero.run(8080, TareaController.class);
}

Eso es todo. Cero.run registra las rutas, levanta el servidor e imprime el puerto y el tiempo de arranque. No hay web.xml, ni contenedor, ni despliegue.

Con todo declarado

App.javaJava
Server servidor = Cero.app()
    .port(8080)
    .loadConfig()
    .views(Templates.fromClasspath("plantillas"))
    .fallback(StaticFiles.fromClasspath("estaticos", "/estaticos"))
    .service(new Catalogo())
    .authenticator(ctx -> sesiones.verificar(ctx.header("Authorization")))
    .use(Cors.allowing("https://app.pe"))
    .use(Csrf.enabled().exempt("/api/"))
    .use(RateLimit.perMinute(300))
    .controllers(TareaController.class, AdminController.class)
    .routes(r -> r.get("/salud", ctx -> "ok"))
    .start();

servidor.await();  // bloquea hasta que se apague
