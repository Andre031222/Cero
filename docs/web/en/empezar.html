01

Installation

Cero is not published to Maven Central yet, so there is an installer. It downloads the package, checks its fingerprint, builds it, leaves the artefacts in your local Maven repository and puts the cero command within reach. It asks for no password and writes nothing outside your home folder.

macOS and Linuxsh
curl -fsSL https://cero.ginit.dev/instalar | sh
WindowsPowerShell
irm https://cero.ginit.dev/instalar.ps1 | iex

Both scripts are served as plain text on purpose: open them in your browser and read them before running them — instalar · instalar.ps1. With --con-pruebas the installer also runs the 1,342 tests as it goes.

And if you would rather do it by hand, it is the same thing step by step:

~/proyectos

Requirements: git, Maven and a JDK 25 or newer. Nothing else — Cero has no external dependencies.

Then, in your pom.xml, take only what you use:

pom.xmlXML
<dependency>
    <groupId>cero</groupId>
    <artifactId>cero-core</artifactId>   <!-- pulls in cero-http -->
    <version>0.3.0</version>
</dependency>

<!-- optional -->
<dependency><groupId>cero</groupId><artifactId>cero-view</artifactId><version>0.3.0</version></dependency>
<dependency><groupId>cero</groupId><artifactId>cero-data</artifactId><version>0.3.0</version></dependency>

<!-- the JDBC driver is your application's business -->
<dependency><groupId>org.postgresql</groupId><artifactId>postgresql</artifactId><version>42.7.3</version></dependency>

02

In five minutes

A controller is an ordinary class. What it returns decides the format: an object is serialised to JSON, a String goes out as plain text, null is a 204. No annotation involved.

Hola.javaJava
import cero.core.*;

@Route("/api/tareas")
public class TareaController {

    @Inject Tareas tareas;

    @Get
    public Object listar(@Query(value = "pagina", orElse = "1") int pagina) {
        return tareas.findPage(pagina, 20);
    }

    @Get("/{id}")
    public Object ver(@Path("id") long id) {
        return tareas.findById(id);
    }

    @Post
    public Object crear(@Body @Valid Tarea tarea) {
        return Result.created(tareas.insert(tarea));
    }
}

public static void main(String[] args) {
    Cero.run(8080, TareaController.class);
}

That is all. Cero.run registers the routes, starts the server and prints the port and the boot time. There is no web.xml, no container, no deployment.

With everything spelled out

App.javaJava
Server servidor = Cero.app()
    .port(8080)
    .loadConfig()
    .views(Templates.fromClasspath("plantillas"))
    .fallback(StaticFiles.fromClasspath("estaticos", "/estaticos"))
    .service(new Catalogo())
    .authenticator(ctx -> sesiones.verificar(ctx.header("Authorization")))
    .use(Cors.allowing("https://app.pe"))
    .use(Csrf.enabled().exempt("/api/"))
    .use(RateLimit.perMinute(300))
    .controllers(TareaController.class, AdminController.class)
    .routes(r -> r.get("/salud", ctx -> "ok"))
    .start();

servidor.await();  // blocks until shutdown
