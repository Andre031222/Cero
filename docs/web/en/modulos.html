02

Server · cero-http

HTTP/1.1 with one virtual thread per connection. It can be used on its own, without cero-core, if all you want is to answer requests.

No frameworkJava
Server.start(8080, (req, res) -> res.text("Hola"));

Options

OptionDefaultWhat for
port80800 picks a free one
host0.0.0.0Listening interface
maxConnections10,000Ceiling on concurrent connections
idleTimeoutMillis30,000Cuts idle connections
handlerTimeoutMillis30,000Frees the connection if the handler hangs
shutdownGraceMillis10,000Waits for in-flight requests on shutdown
maxBodyBytes10 MBMaximum body size
maxHeaderBytes32,768Maximum header size
maxHeaderCount100Maximum number of headers
maxKeepAliveRequests1,000Requests per connection
sessionTimeoutMillis30 minSession expiry on inactivity
gzipMinBytes1,024Compression threshold; 0 disables it
requireHosttrueRequires Host on HTTP/1.1
TLS and static filesJava
ServerOptions opciones = ServerOptions.builder()
    .port(8443)
    .tls(Tls.fromKeystore(Path.of("certificado.p12"), "clave".toCharArray()))
    .maxBodyBytes(50L << 20)
    .build();

StaticFiles.from(Path.of("publico"))                   // from disk
StaticFiles.fromClasspath("estaticos", "/estaticos")  // from the JAR

Static files emit ETag and Last-Modified, answer 304 to If-None-Match, and block any attempt to escape the root directory.

03

Views · cero-view

Compiled and cached templates, with inheritance. HTML escaping is the default behaviour: raw output has to be asked for explicitly.

SyntaxWhat it does
{{ expr }}Interpolates, escaping the HTML
{{& expr }}Interpolates without escaping
{% if c %} … {% end %}Conditional, with {% elseif %} and {% else %}
{% for x in lista %}Loop, with {% else %} if it comes out empty
{% include "parcial.html" %}Inserts another template
{% extends "base.html" %}Inherits from a layout
{% block nombre %}Defines or overrides a block
{# nota #}Comment, never reaches the HTML

Inside a loop

VariableValue
loop.indexPosition from 0
loop.numberPosition from 1
loop.first / loop.lastWhether it is the first or the last
loop.sizeHow many elements there are
lista.htmlTemplate
{% extends "base.html" %}

{% block titulo %}Tareas · {{ pendientes }} pendientes{% end %}

{% block contenido %}
{% if tareas %}
  <ul>
  {% for t in tareas %}
    <li class="{{ t.etiqueta }}">
      {{ loop.number }}. {{ t.titulo }}
      {% if !loop.last %}<hr>{% end %}
    </li>
  {% end %}
  </ul>
{% else %}
  <p>No hay ninguna tarea.</p>
{% end %}
{% end %}

Expressions accept dotted paths (autor.nombre), list indexes (items.0), .size, literals, and the operators == != < > <= >=, and, or, ! and parentheses. Nothing else: it is deliberately small.

Configuring the engineJava
Templates.fromClasspath("plantillas")          // inside the JAR
Templates.from(Path.of("plantillas"))          // from disk
    .suffix(".html")                          // so you can write view("lista")
    .reload(true)                             // recompiles on edit, during development
04

Data · cero-data

Plain JDBC, no ORM. Everything goes through prepared statements; table and column names are validated character by character before the database is touched.

ConnectingJava
DataSources.registerDefault(
    Pool.to("jdbc:postgresql://localhost/tareas")
        .credentials("usuario", "clave")
        .maxSize(10)
        .build());

Queries

DbJava
Db db = Db.open();

Rows filas = db.select("tareas", "hecha = ?", false);
Row  una   = db.selectOne("tareas", "id = ?", 7);
long total = db.count("tareas", null);

List<Tarea> t = db.query(Tarea.class, "SELECT * FROM tareas WHERE prioridad = ?", "alta");
Page<Row> pag = db.page("tareas", "hecha = ?", 1, 20, false);

db.insert("tareas", Row.of("titulo", "Escribir", "prioridad", "alta"));
db.update("tareas", Row.of("hecha", true), "id = ?", 7);
db.delete("tareas", "id = ?", 7);

// named parameters
db.queryNamed("SELECT * FROM tareas WHERE prioridad = :p", Map.of("p", "alta"));

Repositories

RepositoryJava
@Table("tareas")
public record Tarea(@Id long id, String titulo,
                   @Column("hecha") boolean completada) {}

@Service
public class Tareas extends Repository<Tarea, Long> {
    public Tareas() { super(Tarea.class); }

    public List<Tarea> pendientes() { return findBy("hecha = ?", false); }
}

tareas.findById(7L)     tareas.findAll()      tareas.findPage(1, 20)
tareas.insert(tarea)     tareas.update(tarea)  tareas.deleteById(7L)
tareas.count()           tareas.existsById(7L)

Transactions

TxJava
Tx.run(() -> {
    cuentas.debitar(origen, monto);
    cuentas.acreditar(destino, monto);      // if this throws, everything is undone
});

long id = Tx.call(() -> pedidos.insert(pedido));
  • Queries inside a transaction share a connection automatically.
  • Nested transactions join the outer one; there are no savepoints.
  • Column names are looked up case-insensitively: H2 and Oracle return TITULO, PostgreSQL returns titulo, and both work.
05

Security

MiddlewareJava
.use(Cors.allowing("https://app.pe").credentials(true))
.use(Csrf.enabled().exempt("/api/"))
.use(RateLimit.perMinute(300).keyBy(ctx -> ctx.header("X-Cliente")))
.use((ctx, cadena) -> {                    // one of your own
    long t0 = System.nanoTime();
    try { return cadena.proceed(ctx); }
    finally { registrar(ctx, System.nanoTime() - t0); }
})
PieceWhat it covers
CorsOPTIONS preflight, credentials, Vary: Origin. With credentials it never answers *: it returns the specific origin.
CsrfToken in the session, constant-time comparison. Reads _csrf from the header, the form or the query string. Exemption by prefix or with @CsrfExempt.
RateLimitWeighted sliding window, X-RateLimit-* and Retry-After headers, configurable key.
Sanitizehtml() strips scripts, styles, iframes and event handlers; text() leaves only text; filename() neutralises paths.
@RequireAuth401 if there is no principal.
@RequireRole("admin")401 when unauthenticated, 403 when the role is insufficient.

Authentication

AuthenticatorJava
.authenticator(ctx -> {
    String token = ctx.header("Authorization");
    if (token == null) return null;         // anonymous
    return Principal.of("andre", "admin");   // id + roles
})

The pipeline order is authenticate → middleware → authorise → bind → invoke → render. That way middleware sees the principal and can at the same time wrap the 401s and 403s to log them.

What the server rejects on its own

Folded headers, duplicate Content-Length, Content-Length alongside Transfer-Encoding, a missing or duplicate Host, control characters in response headers, and escapes from the root directory in static files.

06

Configuration

loadConfig() reads application.properties from the classpath and the current directory, and on top of that applies environment variables prefixed with CERO_ and system properties prefixed with cero.

application.propertiesProperties
server.port=8080
server.maxConnections=5000
server.gzipMinBytes=512

db.url=jdbc:postgresql://localhost/tareas
db.usuario=cero
db.pool=10
Reading itJava
Config config = Config.load();

config.get("db.url")                    config.getInt("db.pool", 5)
config.getBoolean("app.debug", false)   config.under("db")

// or bind it to a record
record Datos(String url, String usuario, int pool) {}
Datos datos = config.bind(Datos.class, "db");

The server.* keys configure the server without writing code: CERO_SERVER_PORT=9000 in the environment changes the port.
