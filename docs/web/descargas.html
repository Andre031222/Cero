02

Maven

Tras ./cero install, los artefactos quedan en tu repositorio local y se declaran como cualquier otro.

pom.xmlXML
<!-- lo mínimo para una API: arrastra cero-http -->
<dependency>
    <groupId>cero</groupId>
    <artifactId>cero-core</artifactId>
    <version>0.3.0</version>
</dependency>

<!-- si sirves HTML -->
<dependency>
    <groupId>cero</groupId>
    <artifactId>cero-view</artifactId>
    <version>0.3.0</version>
</dependency>

<!-- si hablas con una base de datos -->
<dependency>
    <groupId>cero</groupId>
    <artifactId>cero-data</artifactId>
    <version>0.3.0</version>
</dependency>

<!-- el driver lo pones tú: este es el único externo -->
<dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <version>42.7.4</version>
</dependency>
03

Qué tomar

Solo HTTP
cero-http · 95 KB
Un servidor con handlers a mano, sin rutas ni inyección. Para un webhook, un healthcheck o un proxy pequeño.
Una API JSON
cero-core · 284 KB
Rutas, inyección, validación, seguridad y métricas. Lo habitual para un servicio.
Una web con HTML
+ cero-view · 322 KB
Añade plantillas con herencia y escapado por defecto.
Con base de datos
+ cero-data · 370 KB
JDBC, pool, transacciones, repositorios y sesiones en tabla. Más el driver de tu motor.
Migrando desde Tomcat
+ cero-adapter-servlet · 382 KB
Despliega la misma aplicación dentro de Tomcat mientras haces el cambio, y vuelve atrás si hace falta.
04

Desde el código

Compilar e instalarShell
git clone git@github.com:Andre031222/Cero.git
cd Cero

./cero install     # compila, prueba e instala en ~/.m2
./cero package     # solo los JAR, con sus tamaños
./cero test        # las 1 624 pruebas
./cero run         # la aplicación de ejemplo en :8080
./cero new mi-app  # un proyecto nuevo, listo para arrancar
./cero docs        # esta documentación, servida por Cero
./cero cache       # qué ocupa, y --purge para vaciarla
./cero clean       # borra lo generado

La aplicación de ejemplo está en java/ejemplo: un gestor de tareas completo con vistas, formularios, base de datos y API REST, con 36 pruebas de punta a punta. Es el mejor sitio por donde empezar a leer.

Comprobar lo que compilaste

HuellasShell
shasum -a 256 java/cero-core/target/cero-core-0.3.0.jar

# debe empezar por 5309738f66a6fbde
05

Requisitos

QuéVersiónPor qué
JDK21 o superior Hilos virtuales: el servidor asigna uno por conexión y sin ellos el modelo no se sostiene. Desarrollado y medido con OpenJDK 25.
Maven3.9+ Solo para compilar. En ejecución no hace falta.
Sistemacualquiera Sin código nativo ni rutas del sistema. Probado en macOS y en Linux; sin verificar en Windows.
Driver JDBCel de tu motor Solo si usas cero-data. Verificado con PostgreSQL 16, MySQL 8 y H2.
Tomcat10.1+ Solo si despliegas con cero-adapter-servlet. En modo normal no se usa.
